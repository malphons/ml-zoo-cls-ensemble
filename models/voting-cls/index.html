Voting Classifier

Classification Ensemble Est. 1994

Combines predictions from multiple classifiers using majority voting (hard) or averaged probabilities (soft), leveraging the wisdom-of-crowds effect for improved accuracy.

Overview

The Voting Classifier is one of the simplest yet most effective ensemble methods. It aggregates predictions from multiple classifiers and outputs the class that receives the most votes (hard voting) or the class with the highest averaged probability (soft voting).

The intuition is the “wisdom of crowds” effect: if each classifier is better than random and their errors are somewhat independent, the majority vote will tend to be more accurate than any individual classifier. Soft voting can outperform hard voting by leveraging the confidence levels of each classifier.

When to Use

  • You have several trained classifiers with complementary strengths
  • You want a simple ensemble without meta-learner complexity
  • Base classifiers produce well-calibrated probabilities (for soft voting)
  • Quick improvement over individual models

Pros

  • Extremely simple to implement
  • Often improves over best individual model
  • Soft voting leverages probability calibration
  • No additional training step (unlike stacking)
  • Easily parallelizable

Cons

  • Cannot learn which model to trust where (unlike stacking)
  • All models weighted equally by default
  • Soft voting requires probability outputs from all models
  • Diminishing returns with correlated classifiers

How It Works

Hard Voting (Majority Rule)

  1. Collect predictions: Each of the $M$ classifiers produces a class label $\hat{y}_m(x) \in \{0, 1, \ldots, K-1\}$.
  2. Majority vote: Return the class that appears most frequently among the $M$ predictions.

Soft Voting (Probability Averaging)

  1. Collect probabilities: Each classifier produces a probability vector $P_m(C_k \mid x)$ for all classes.
  2. Average probabilities: Compute $\bar{P}(C_k \mid x) = \frac{1}{M}\sum_{m=1}^{M} P_m(C_k \mid x)$.
  3. Predict: Return $\arg\max_k \bar{P}(C_k \mid x)$.

Key Equations

Hard Voting

$$\hat{y}_{\text{hard}}(x) = \text{mode}\bigl\{\hat{y}_1(x),\, \hat{y}_2(x),\, \ldots,\, \hat{y}_M(x)\bigr\}$$

Soft Voting

$$\hat{y}_{\text{soft}}(x) = \arg\max_k \frac{1}{M}\sum_{m=1}^{M} P_m(C_k \mid x)$$

Weighted Voting

$$\hat{y}_{\text{weighted}}(x) = \arg\max_k \sum_{m=1}^{M} w_m \cdot P_m(C_k \mid x)$$

where $\sum_{m} w_m = 1$ and weights $w_m$ can be set by cross-validation performance.

Condorcet's Jury Theorem

If each of $M$ independent classifiers has accuracy $p > 0.5$, the probability that the majority vote is correct:

$$P_{\text{correct}} = \sum_{k=\lceil M/2\rceil}^{M}\binom{M}{k}p^k(1-p)^{M-k} \xrightarrow{M \to \infty} 1$$

scikit-learn

Python
from sklearn.ensemble import VotingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score

# Define base estimators
estimators = [
    ('lr', LogisticRegression()),
    ('dt', DecisionTreeClassifier(max_depth=5)),
    ('svm', SVC(probability=True))
]

# Hard voting
hard_voter = VotingClassifier(
    estimators=estimators, voting='hard'
)

# Soft voting
soft_voter = VotingClassifier(
    estimators=estimators, voting='soft'
)

# Weighted soft voting
weighted_voter = VotingClassifier(
    estimators=estimators, voting='soft',
    weights=[2, 1, 1]  # trust LR more
)

hard_voter.fit(X_train, y_train)
soft_voter.fit(X_train, y_train)
print(f"Hard: {accuracy_score(y_test, hard_voter.predict(X_test)):.4f}")
print(f"Soft: {accuracy_score(y_test, soft_voter.predict(X_test)):.4f}")
