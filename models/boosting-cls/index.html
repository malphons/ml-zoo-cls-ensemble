Gradient Boosting Classifier

Classification Ensemble Est. 2001

Sequentially builds trees that correct errors of previous trees by fitting to negative gradients of the deviance loss. Each round progressively refines the decision boundary.

Boosting round:5

Overview

Gradient Boosting for classification works by fitting a sequence of shallow decision trees to the negative gradient of the log-loss (deviance). At each iteration, a new tree is added that corrects the errors of the current ensemble, gradually improving the decision boundary. With proper regularization (learning rate, max depth, subsampling), it achieves state-of-the-art performance on structured/tabular data.

When to Use

  • Tabular/structured data classification
  • You need high accuracy and can afford slower training
  • Feature interactions are important
  • You have enough data to avoid overfitting

Pros

  • Among the most accurate classifiers for tabular data
  • Handles mixed feature types
  • Built-in feature importance
  • Flexible loss functions

Cons

  • Sequential training (slow)
  • Many hyperparameters to tune
  • Can overfit without regularization
  • Less interpretable than single trees

How It Works

  1. Initialize with log-odds: $F_0(x) = \log(\hat{p}/(1-\hat{p}))$ using base class proportions.
  2. Compute pseudo-residuals: $r_i = y_i - p_i$ where $p_i = \sigma(F(x_i))$. These are the negative gradients of the deviance loss.
  3. Fit a small tree to the pseudo-residuals.
  4. Update: $F_{t+1}(x) = F_t(x) + \eta \cdot h_t(x)$ where $\eta$ is the learning rate.
  5. Repeat for $T$ rounds. Final probabilities via sigmoid: $p(x) = \sigma(F_T(x))$.

Move the boosting round slider to see how the boundary improves with each round.

Key Equations

Deviance Loss

$$L(y, F) = -[y \log p + (1-y) \log(1-p)], \quad p = \sigma(F) = \frac{1}{1+e^{-F}}$$

Pseudo-Residuals

$$r_i = -\frac{\partial L}{\partial F(x_i)} = y_i - p_i$$

Additive Update

$$F_t(x) = F_{t-1}(x) + \eta \cdot h_t(x)$$

Regularization

$$\Omega(h_t) = \gamma T + \frac{1}{2}\lambda \sum_{j=1}^T w_j^2$$

where $T$ = number of leaves, $w_j$ = leaf weights, $\gamma$ and $\lambda$ are penalties.

scikit-learn

Python
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import accuracy_score

model = GradientBoostingClassifier(
    n_estimators=100, learning_rate=0.1,
    max_depth=3, subsample=0.8, random_state=42
)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.4f}")
