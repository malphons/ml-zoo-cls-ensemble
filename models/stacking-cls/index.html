Stacking Classifier

Classification Ensemble Est. 1992

Trains a meta-learner to optimally combine predictions from diverse base models, learning which base model to trust in different regions of feature space.

Overview

Stacking (Stacked Generalization) is a powerful ensemble technique that combines multiple heterogeneous base classifiers through a second-level meta-learner. Unlike bagging or boosting, which use the same type of base learner, stacking leverages the complementary strengths of fundamentally different models.

The key insight is that different models make different types of errors. A meta-learner trained on the base models' outputs can learn which model to trust in which regions of the feature space, achieving better overall performance than any single base model.

When to Use

  • You have diverse base models with complementary strengths
  • You want to squeeze out the best possible accuracy
  • You have enough data to train both levels without overfitting
  • Competitions or high-stakes production where every percentage point matters

Pros

  • Often outperforms individual models and simple ensembles
  • Can combine any types of base classifiers
  • Meta-learner adapts to base model strengths automatically
  • Flexible architecture (multiple stacking layers possible)

Cons

  • Computationally expensive (trains many models)
  • Prone to overfitting without proper cross-validation
  • Complex to tune and debug
  • Less interpretable than single models

How It Works

  1. Train base models: Fit $M$ diverse base classifiers $h_1, \ldots, h_M$ on the training data. Common choices include logistic regression, decision trees, SVM, and kNN.
  2. Generate meta-features: Use cross-validation to produce out-of-fold predictions from each base model. For each training sample, collect the predictions from the base model that did not train on it.
  3. Train meta-learner: Fit a second-level model $g$ on the meta-features (the matrix of base model predictions). Common meta-learners include logistic regression or a simple linear model.
  4. Predict: For new data, run all base models to get predictions, then pass these through the meta-learner for the final classification.

Key Equations

Base Model Predictions

$$\mathbf{z}_i = \bigl(h_1(x_i),\, h_2(x_i),\, \ldots,\, h_M(x_i)\bigr) \quad \text{for each training sample } x_i$$

Meta-Learner

$$\hat{y} = g(\mathbf{z}) = g\bigl(h_1(x),\, h_2(x),\, \ldots,\, h_M(x)\bigr)$$

A common choice is logistic regression: $g(\mathbf{z}) = \sigma(w_0 + w_1 z_1 + \cdots + w_M z_M)$.

Cross-Validated Meta-Features

$$z_{i,m} = h_m^{(-k(i))}(x_i)$$

where $h_m^{(-k(i))}$ is model $m$ trained on all folds except the fold containing sample $i$. This prevents information leakage.

scikit-learn

Python
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score

# Define base estimators
estimators = [
    ('dt', DecisionTreeClassifier(max_depth=5)),
    ('svm', SVC(kernel='rbf', probability=True)),
    ('knn', KNeighborsClassifier(n_neighbors=5))
]

# Create stacking classifier with logistic meta-learner
model = StackingClassifier(
    estimators=estimators,
    final_estimator=LogisticRegression(),
    cv=5,  # cross-validation for meta-features
    stack_method='auto'
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)
print(f"Accuracy: {accuracy_score(y_test, y_pred):.4f}")
